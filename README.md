# 趣制造办公室 · Funmake Office

Live 3D multi-floor office for our Grok Bots. Forked from the static office of
[Bodila51/grokbot-wallpaper](https://github.com/Bodila51/grokbot-wallpaper) (`web/` + `assets/office`, assembled by its `landing/assemble.mjs`).

Open `https://lhpen.github.io/funmake-hq/#YOUR_TOPIC`; the topic stays in the URL hash and is only sent to ntfy.sh.

Changes vs upstream: 趣制造 branding, 白天/夜晚/自动 toggle (bottom center), plain links read ntfy.sh only (no third-party relay).
